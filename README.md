# 修正内容・保存手順

## 主な修正

- 画面と入力欄を明るい色ベースに統一。DADSを参考にした配色、見出し構造、入力ラベル、キーボードフォーカス表示は維持。
- 画像出力用のレイアウトを画面表示から分離し、見出し・議案名・複数行の文章を折り返して全体を描画。画像端で文字が隠れないように調整。
- 告知・採決すべてのバナーを、添付見本を参考にした淡い背景・中央見出し・白いカードのデザインへ統一。既存アイコンと番号表示の使い方は維持。全校委員会はカード構成を保ったまま淡い緑系に変更。
- Teams投稿用の横長採決は議案数に応じて1～3列に配置。5件以上は票数と結果をカード内にまとめ、縮小表示でも確認しやすいサイズを優先。
- スマホ向け採決は件数に応じて1～2列に配置。票数を大きくし、3桁以上は桁数に応じて縮小してセル内に収める。入力欄から画像用テキストへ変換する際も桁数指定を保持。
- 7議案の横長・縦長とも余白を調整し、標準条件でそれぞれ16:9・9:16に収める。非常に長い議案名・文章など、指定比率内に収めると読みにくくなる場合は画像の高さを広げ、文字を切り落とさない。
- すべてのバナーに正方形（1:1）保存を追加。正方形出力は横長レイアウトの単純縮小ではなく専用構成とし、告知・行事予告は見出しを上に置いて日時・場所・議題を縦方向に大きく展開。開催報告は開催情報の下に議題・要旨・URLを縦積みし、採決結果は2列カードで票数・議案名を拡大。キャンバスの高さを活用し、標準内容は自動縮小なしで収まるよう調整。
- 議案名・結果欄・カードを最小幅対応にし、長い文言やタブレット幅でもカード端からはみ出しにくいよう折り返しを強化。
- 採決結果の票数グリッドで、灰色・水色・桃色の塗りの左右端に角丸を追加。背面カードの角丸と揃え、区切り線・中央のセル配置は維持。
- 旧版の標準タイトルのみ「採決結果」に整え、利用者が入力した独自タイトルはそのまま保持。
- iPadOSの共有シートから写真アプリへ保存できる案内を追加。ファイルへの保存・画像長押しも案内。
- 自動保存でブラウザー側の保存領域が利用できない場合の例外処理、長文入力の伸長、タブレット幅でのレイアウトを改善。
- 行事検討委員会の専用バナーを追加。「予告」は日時・場所・議題・備考、「報告」は開催回・開催日・議題・2〜3行を想定した要旨・議事要旨の閲覧URLを入力でき、横長・正方形・縦長PNGで保存可能。開催回・開催日は各形式で同期し、データは既存の委員会データと分けて端末内に自動保存。
- 行事検討委員会のバナーは赤系の淡いガラス調。議題・要旨・リンク用のアイコンを追加し、URLはhttp/httpsだけを新しいタブで開く。PNG画像にはURL文字列を表示し、画像内のリンクはクリックできないことと、Teams投稿本文にもURLを添える方法を案内。
- 「予告・報告」切替ボタンは選択中を濃い赤背景・白文字とし、文字の視認性を確保。
- 既存のDADSを参考にした見出し階層、フォームラベル、フォーカス表示、押下状態の伝達は保持。行事検討委員会の赤は依頼に基づくアプリ独自のテーマ色であり、DADS公式色・公式部品と誤認させない設計。

## iPadで画像を保存する手順

1. 保存したい形式（横長16:9・正方形1:1・縦長9:16）の保存ボタンを押します。
2. プレビュー画面の「共有シートを開く」を押します。
3. 共有シートで「画像を保存」を選びます。

共有シートが利用できない場合は「ファイルに保存」を使うか、プレビュー画像を長押ししてください。共有シートや「画像を保存」の表示は、iPadOSのバージョン・ブラウザー・共有メニュー設定によって異なる場合があります。

## 検証

- `node --check` で埋め込みJavaScript構文を確認。
- `pnpm build` 成功。
- ブラウザー上で長文を含む告知画像（横長・縦長）と7議案の採決画像（横長・縦長）のPNG生成を確認。長文も折り返して表示され、末尾を含めて画像枠内に収まることを確認。
- PC・iPad相当の幅（768、820、1024、1280px）で7議案と長文を含むカードを検査し、ページの横スクロールとカード内の横はみ出しがないことを確認。1議案・7議案の縦長PNGはどちらも1080×1920px。通常の2桁票数は拡大し、多桁票数は出力後にも桁別サイズが適用されることを確認。
- 横長・縦長の採決PNGで左右端セルの角部分と塗りの内側を画素比較し、角では背景色、内側では各セル色が描画されて角丸が出力画像にも反映されたことを確認。
- iPadOS相当のタッチ端末判定をブラウザーで模擬し、長押し・「ファイルに保存」案内が表示される共有保存プレビューを確認。**実機のiPadでは未検証**。
- 7議案の最終画像寸法：横長 2560×1440 px（16:9）、正方形 1800×1800 px（1:1）、縦長 1080×1920 px（9:16）。告知画像も横長 2560×1440 px、正方形 1800×1800 px、縦長 1080×1920 px。
- 行事検討委員会の予告・報告について入力同期、自動保存、http/https以外のURLをリンク化しないことをブラウザーで確認。予告・報告の横長・正方形・縦長PNGを生成し、開催回・開催日が報告画像に反映されることを確認。寸法は横長2560×1440px、正方形1800×1800px、縦長1080×1920px。長い議事要旨URLも画像内に収まることを確認。既存の全校委員会告知も横長PNGで確認。
- 768px（iPad縦向き相当）、1024px（iPad横向き・小型PC相当）、1280px（PC相当）でページ幅と報告バナーを検査。狭い画面のプレビューは内容に応じて高さを伸ばして切れを防止し、保存画像は画面幅に依存しない16:9キャンバス（CSS 1280×720px、PNG 2560×1440px）で全主要項目が収まることを確認。**実機iPadの保存操作、および実際に利用するPDF URLへの接続は未検証**。
- 正方形PNGは告知・7議案の採決・行事予告・行事報告で生成し、すべて1800×1800px、書き出し時の自動縮小率1.0で収まることをブラウザーで確認。告知はタイトル・日時・場所・議題の情報パネルがキャンバスの縦方向を広く使うこと、7議案採決は各カードの議案名・票数欄が読める大きさで全件収まることを確認。報告は長めの議題・2行要旨・長いHTTPS URLを含めて試験し、見出しからURLまで縦積みで枠内に収まり、以前のように情報が中央の小領域へ偏らないことをプレビューで確認。
- DADSは既存画面の設計参照として保持。追加テーマ・ガラス調はアプリ固有の実装で、正式なDADS適合試験を行ったものではない。
