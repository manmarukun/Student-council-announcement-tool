# 生徒会運営アプリ — 使い方と仕様

## 1. ツールの概要

生徒会や委員会の会議・行事に関する情報を入力し、SNSやTeamsなどで共有できるバナーを作成するブラウザーアプリです。次の3種類のバナーを作成し、プレビューで確認したうえでPNG画像として保存できます。

- **開催告知**：会議の日時、場所、議題、補足を掲載
- **採決結果**：議案ごとの投票数と結果を掲載
- **行事検討委員会**：会議の予告、または会議内容の報告を掲載

画面のレイアウトは、PCでは入力フォームとプレビューを横並びにし、画面幅が狭い場合は縦並びに切り替わります。プレビューの比率を変えても、バナー本体のレイアウトを保ったまま表示サイズを調整します。

## 2. 基本的な使い方

1. HTMLファイルを対応ブラウザーで開きます。
2. 画面上部のタブから「開催告知」「採決結果」「行事検討委員会」のいずれかを選びます。
3. 入力欄を編集します。入力内容はプレビューに反映され、ブラウザー内にも自動保存されます。
4. 「保存形式（比率・固定寸法）」で「横長 16:9」「正方形 1:1」「縦長 9:16」を選びます。
5. プレビューで内容を確認し、「PNGを生成する」を押します。
6. 生成された画像を確認し、「ダウンロード」または利用可能な環境では「共有」を選びます。

## 3. バナーの種類と入力項目

### 開催告知

- 委員会名
- 委員会の色テーマ：全校（緑）、代表（青）、行事（赤）
- タイトル
- 開催日、時刻
- 場所
- 議題
- 補足・備考（任意）

### 採決結果

- 委員会名と色テーマ
- タイトル
- 開催日
- 会議名・備考
- 議案名
- 各議案の棄権・保留・賛成・反対の数
- 各議案の結果：可決、否決、継続審議
- 全体のまとめ（任意）

「＋ 議案を追加」で議案を増やし、議案行の削除ボタンで不要な議案を削除できます。議案数が増えると、バナー内のカードは文字サイズや余白を調整して表示されます。画面上では7件までの表示が想定されています。

### 行事検討委員会

委員会名を入力し、「予告」または「報告」を選択します。

**予告**では、開催日、時刻、場所、議題、備考を入力します。

**報告**では、開催回、開催日、議題、要旨、議事要旨PDFのURLを入力します。URL欄は `https://` または `http://` で始まるURLを受け付けます。URLはバナー画像内に文字列として表示されますが、画像内からリンクを開くことはできません。

## 4. 出力・プレビュー仕様

| 比率 | 内部レイアウト寸法 | PNG出力サイズ |
|---|---:|---:|
| 横長 16:9 | 1280 × 720 px | 2560 × 1440 px |
| 正方形 1:1 | 900 × 900 px | 1800 × 1800 px |
| 縦長 9:16 | 540 × 960 px | 1080 × 1920 px |

PNGは内部レイアウトを2倍の解像度で出力します。プレビューの縮小率は画面幅と画面の高さに応じて調整されます。プレビューは出力比率に合わせて表示されます。

画像生成には `html2canvas` を利用します。生成した画像は確認モーダルに表示され、ダウンロードできます。ブラウザーがファイル共有に対応している場合は「共有」ボタンも表示されます。

## 5. 日付の入力

日付は、たとえば `10月15日（木）` や `2026/10/15` のように入力できます。アプリが日付を判別できる場合は、日付の数字を大きく表示します。年を含む形式で曜日が入力されていない場合、曜日を自動計算します。判別できない形式の場合は、入力文字列をそのまま表示します。

入力された日付が実在する日付かどうかの厳密な検証は行いません。曜日を括弧付きで入力した場合は、その曜日の表記が優先されます。

## 6. 保存とプライバシー

- 入力した内容、選択中のタブ、比率などは、ブラウザーの `localStorage` に自動保存されます。
- 保存データは、そのブラウザー内に保持されます。別の端末や別のブラウザーとは自動同期されません。
- ブラウザーのサイトデータを削除すると、保存内容も消える場合があります。
- HTML内の説明では、入力データはブラウザー内にのみ保存される仕様です。

## 7. 利用上の注意

- PNG生成用の `html2canvas` はCDNから読み込まれます。ネットワーク接続やCDNへのアクセスができない場合、入力・プレビュー・自動保存は使えますが、PNG生成は利用できません。
- PNG生成が失敗した場合は、ページを再読み込みする、文章量を減らす、別の比率やブラウザーを試すなどの方法をお試しください。
- 共有やファイル保存の動作は、ブラウザー、OS、バージョン、端末の設定によって異なります。iPadではダウンロードのほか、共有シートや画像の長押し保存が利用できる場合があります。
- 入力内容を画像として共有する前に、日時・場所・投票数などに誤りがないか確認してください。

## 8. 画面構成

- **上部タブ**：バナーの種類を切り替えます。
- **入力フォーム**：選択中のバナーに必要な情報を編集します。
- **出力設定**：PNG画像の比率を選択します。
- **プレビュー**：現在の入力内容を出力比率で確認します。
- **PNG生成ボタン**：画像を生成して確認モーダルを開きます。
